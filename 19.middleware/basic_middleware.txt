Middleware
===========
=> A Middleware is a function that intercepts every HTTP request and response in your 
    FastAPI application.
=> It allows you to run code before a request is processed by a specific endpoint and 
    after a response is generated, enabling tasks like adding headers, logging, or 
    measuring performance.
=> The Middleware runs for every HTTP request to any endpoint (e.g., if you add more
    endpoint, the Middleware will still execute for them).
=> Middleware applies globally to all HTTP requests (not just specific endpoints)
    unless filtered by logic the Middleware (e.g., checking the request URL).


Creating Middleware
=====================
=> Middleware is created using the @app.middleware("http") decorator on an async function.
=> The middleware function takes:
    - request: The incoming HTTP request
    - call_next: A function that passes the request to the next layer (path operation) and 
        returns the response. 


When Middleware is executed
============================
=> Before the request reaches the path operation (endpoint).
=> After the response is generated by the endpoint, before it's returned to the client.


ASGI Middleware are custom or third-party middleware that follow the ASGI spec.
ASGI Middlewares are typically classes that take an ASGI app and Configuration parameters.
